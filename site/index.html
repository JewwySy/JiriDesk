LESS SETUP. MORE CONNECTION.

From here to there.
In three steps.

No account needed. Install on both computers, then connect using the app.

  1. Make yourself at home

    Download and install JiriDesk on both Windows computers.

  2. Share the details

    Get the ID and password from the computer you want to reach.

  3. Connect and get to it

    Enter the remote ID in JiriDesk. Use its password or ask the host to approve.

Early preview. Remote connections need a reachable signaling server configured in Settings → Connection. The app currently defaults to a local server. macOS compatibility has not yet been tested.

Features

Everything in version 0.3.0.

Permanent ID

A 9-digit ID created on first launch. It stays the same, so you can reconnect any time.

Unattended access

Connect with the password and get in without anyone clicking Accept on the other side.

Approve each connection

Connect without a password and the host sees a prompt: Allow (full control), View-only, or Deny.

Mouse, keyboard, scroll

Click, right-click, drag, type, and scroll on the remote screen.

Live screen

The remote screen streams to you in real time over WebRTC.

Attempt limits

The server limits connection attempts so passwords cannot be guessed quickly.

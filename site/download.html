WINDOWS INSTALL GUIDE

A few clicks.
Then you're in.

  1. Download the installer

    Save JiriDesk-Setup.exe using the Windows button above.

  2. Run the setup wizard

    Choose the installation folder and finish setup. This preview is unsigned; Windows may show a publisher warning. Verify the source before proceeding.

  3. Open and configure JiriDesk

    Launch from Desktop or Start. Configure a reachable signaling server under Settings → Connection on both computers, then use the remote ID to connect.

Support

The status light says Offline

JiriDesk cannot reach its server. Check your internet connection and the server address under Settings, Connection. It reconnects automatically every few seconds.

"Offline or unknown ID"

The ID is mistyped, or JiriDesk is not running on that computer. It must be open and online on the host.

Connected, but the screen is black or never appears

The two computers could not make a direct connection, which happens on strict networks such as mobile data or some offices. A relay server for this is planned.

I can see the screen but my mouse and keyboard do nothing

The host chose View-only, or connected you with a prompt and picked the wrong option. Reconnect and ask for full control. Also, Windows blocks input into elevated (administrator) windows and the UAC prompt unless JiriDesk itself runs as administrator.

How do I change my password?

Click New next to the password under Settings, Access to generate a fresh one.

Wrong password

Passwords are case-sensitive. Check the current password on the host, since it changes when the host clicks New.

Too many attempts

After 10 connection attempts in a minute, wait a minute and try again.

Windows SmartScreen or antivirus warns about the installer

The installer is not code-signed yet. If you downloaded it from this site, choose More info, then Run anyway.
